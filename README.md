# 3DPrintersMaterialProfiles
Репозиторий профилей материалов

---
***Профили печати, предлагаемые производителем*** – это пресеты, базовые настройки и рекомендации. Пользователь должен понимать и уметь настраивать параметры печати под свои задачи, т.к. каждый филамент и каждая 3D модель требует уникальных настроек. Производитель не несет ответственности за неправильно подобранные пользователем настройки печати.
