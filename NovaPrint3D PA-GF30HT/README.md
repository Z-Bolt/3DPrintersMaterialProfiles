Данный профиль предназначен для печати материала NovaPrint3D PA-GF30HT соплом из закаленной стали диаметром 0.6мм на обычном стекле при использовании адгезива на основе PVP K-90, дистиллированной воды и изопропилового спирта (в соотношении 5/50-100/350-400). С другими адгезивами данный филамент может некачественно держаться за стол и отклеиваться.
